# Paradise Nursery - e-plantShopping

Welcome to **Paradise Nursery**! 

This is the final project for the React and Redux course. It is an e-commerce platform for purchasing houseplants.

## Features
- **Landing Page**: Provides an overview of the company with a visually appealing background.
- **Product Listing**: Displays different categories of houseplants. Users can add plants to the shopping cart.
- **Shopping Cart**: Users can view selected plants, increment/decrement quantities, delete items, and view total costs.

## Technologies Used
- React
- Redux Toolkit (State Management)
- CSS for Styling
- Vite (Build Tool)

## Getting Started
To run this project locally, ensure you have Node.js installed, then:
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the development server.
